<task type="auto">
  <name>Task 1: Bypass PagedAttention for encoder-only models and wire embed() through real encoder</name>
  <files>crabinfer-server/src/lib.rs, crabinfer-core/src/serving/engine_loop.rs, crabinfer-core/src/serving/worker_pool.rs, crabinfer-server/src/state.rs</files>
  <action>
    The key insight from the research: encoder-only models have no KV cache, no generation loop, no autoregressive
    decoding. They must bypass the PagedAttention engine entirely. The recommended approach is Option 2 from
    06-RESEARCH.md: skip starting the engine loop for embedding models, hold the model directly for synchronous
    embed() calls.

    **Step 1: Add embedding_model field to EngineHandle**

    In `crabinfer-core/src/serving/engine_loop.rs`:
    - Add `embedding_model: Option<Arc<Mutex<Box<dyn ModelRunner>>>>` field to `EngineHandle`.
    - Update the `Clone` impl to clone this field.
    - Add a new constructor `pub fn new_embedding_only(model: Box<dyn ModelRunner>, tokenizer: Tokenizer) -> Self`:
      - Does NOT start a background thread
      - Does NOT allocate KV cache blocks
      - Sets `request_tx` to a dummy channel (or use Option<Sender>)
      - Sets `embedding_model` to `Some(Arc::new(Mutex::new(model)))`
      - Sets `embed_table` to None (not needed — we use the full model)
      - Sets eos_token_id to 0 (unused), max_in_flight to 0, dummy atomics

    - Update `embed()` method:
      - Check `self.embedding_model` first. If Some, lock the model, tokenize each text,
        call `model.embed(&token_ids_tensor)` to get [hidden_size] vector, convert to Vec<f32>.
      - If None, fall through to existing embed_table / hash fallback path.
      - For the embedding model path, tokenize with the stored tokenizer, create a Tensor of
        token IDs on CPU, call model.embed(), and collect results.

    **Step 2: Update WorkerPool to handle embedding-only EngineHandles**

    In `crabinfer-core/src/serving/worker_pool.rs`:
    - No structural changes needed — WorkerPool already delegates embed() to workers[0].
    - The WorkerPool wraps EngineHandle instances; when EngineHandle has an embedding_model,
      embed() already works through the updated EngineHandle.

    **Step 3: Server-side embedding-only model loading path**

    In `crabinfer-server/src/lib.rs`, in `load_serving_engine()`:
    - After loading the model from safetensors (around line 295-298), detect if it's embedding-only:
      ```rust
      // After: let model = load_model_from_safetensors(...)?;
      // Detect embedding-only architecture from config.json
      let arch_probe: HfArchitectureProbe = serde_json::from_str(&config_text)?;
      let architecture = ModelArchitecture::detect(&arch_probe.architectures, arch_probe.model_type.as_deref());

      if architecture.is_embedding_only() {
          tracing::info!("Detected embedding-only model — skipping PagedAttention engine");
          // Create embedding-only EngineHandle (no engine loop, no KV cache)
          let handle = EngineHandle::new_embedding_only(model, tokenizer);
          // Wrap in single-worker WorkerPool
          let pool = WorkerPool::new(vec![handle]);
          return Ok((None, Some(pool), model_info, model_name));
      }
      ```
    - This must happen BEFORE the KV cache estimation and ServingEngineConfig creation code.
    - The `model_info.architecture` for BERT/NomicBert should be set to "bert" or "nomic_bert" (not "llama").

    **Step 4: Handle architecture name in chat template mapping**

    In the architecture detection block (around line 311-332 in lib.rs), add:
    ```rust
    "bert" | "nomic_bert" => "bert".to_string(),
    ```
    (BERT doesn't use chat templates, but this prevents defaulting to "llama".)

    **Step 5: WorkerPool::new() may need to be made pub if not already**

    Check if WorkerPool has a constructor that takes a Vec<EngineHandle>. If not, add one or use
    the existing builder pattern. The current WorkerPool likely constructs handles internally — we
    need a way to inject a pre-built handle.

    If WorkerPool doesn't support external handle injection, add:
    ```rust
    pub fn from_handles(handles: Vec<EngineHandle>) -> Self {
        Self { workers: handles, next: AtomicUsize::new(0), block_size: 16 }
    }
    ```

    CRITICAL: Do NOT call estimate_kv_cache_blocks() for embedding models — it will panic or
    produce nonsensical results because encoder-only models have num_kv_heads=num_heads and
    no KV cache concept.

    CRITICAL: The `request_tx` in the embedding-only EngineHandle must not cause panics.
    Use an unbounded channel and drop the receiver, or use Option<Sender> with None.
    The safest approach: create a channel pair and immediately drop the receiver — sends will
    return Err but embed() won't use the channel at all.
