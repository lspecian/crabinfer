so that `embed()` can run a real encoder forward pass instead of the token-table lookup stub.

    1. Add `Bert` and `NomicBert` variants to `ModelArchitecture` enum in `safetensors_loader.rs`.
    2. Update `ModelArchitecture::detect()` to recognize:
       - architectures containing "nomicbertmodel" or model_type "nomic_bert" -> NomicBert
       - architectures "bertmodel" / "robertamodel" or model_type "bert" / "roberta" -> Bert
       - Check NomicBert BEFORE Bert (more specific first), and both BEFORE the existing Llama default fallback.
    3. Add `pub fn is_embedding_only(&self) -> bool` method to ModelArchitecture returning true for Bert|NomicBert.
    4. Create `crabinfer-core/src/serving/models/bert.rs` with:
       - `pub struct BertEmbeddingRunner` wrapping `candle_transformers::models::bert::BertModel`, a `ModelConfig`, and `Device`.
       - Constructor `pub fn from_safetensors(model_dir: &Path, device: &Device, serving_dtype: DType) -> Result<Self>` that:
         a. Reads config.json and deserializes to `candle_transformers::models::bert::Config`
         b. Opens safetensors via `VarBuilder::from_mmaped_safetensors`
         c. Calls `BertModel::load(vb, &config)` (candle-transformers handles the `model_type` prefix fallback internally)
         d. Builds a `ModelConfig` from the BertConfig fields (set num_kv_heads=num_heads, head_size=hidden/heads, rope_theta=0, rope_dim=0)
       - Implement `ModelRunner` trait:
         - `forward()`: return `Err("BertEmbeddingRunner is encoder-only; use embed() instead")`
         - `embed(input_ids)`: reshape [num_tokens] to [1, seq_len], create zeros token_type_ids, create ones attention_mask, call `self.model.forward(&input_ids_2d, &token_type_ids, Some(&attention_mask))`, then call `masked_mean_pool` + L2 normalize. Return [hidden_size] 1-D tensor.
         - `clone_model()`: clone by re-wrapping (BertModel fields are not Clone, but candle tensors are Arc-backed — implement via storing the VarBuilder data or storing model path for reload. Simplest: store model data in Arc and share. For now, since embedding models are not multi-worker, return an error or use a simple approach).
         - `num_layers()`, `num_kv_heads()`, `head_size()`, `num_heads()`, `config()`: delegate to stored ModelConfig.
    5. Add helper `pub fn masked_mean_pool(hidden_states: &Tensor, attention_mask: &Tensor) -> Result<Tensor>`:
       - hidden_states: [batch, seq_len, hidden_size], attention_mask: [batch, seq_len]
       - Expand mask to [batch, seq_len, 1], broadcast_mul with hidden_states, sum(1), divide by mask.sum(1)
       - L2-normalize the result: divide by sqrt(sum of squares) per row
       - Return [batch, hidden_size] (or squeeze to [hidden_size] for batch=1)
    6. Add `pub mod bert;` to `models/mod.rs`.
    7. Add `Bert` dispatch case in `load_model_from_safetensors_with_backend` match block (after architecture detection):

       ```rust
           let model = super::models::bert::BertEmbeddingRunner::from_safetensors(
               model_dir, device, weight_dtype,
           )?;
           return Ok(Box::new(model));
       }
       ```

    IMPORTANT: For `clone_model()`, since embedding models won't use multi-worker mode, implement a simple version that panics with "Embedding models do not support clone_model" or stores the path and reloads. The simplest correct approach: store the model_dir path and device in the struct, and reload on clone.

    NOTE: NomicBert dispatch and runner will be added in Task 2.

    - test_nomic_bert_embed_shape: NomicBertRunner::embed() on random weights returns tensor of shape [hidden_size]
    - test_nomic_bert_forward_returns_error: NomicBertRunner::forward() returns Err (encoder-only)

  <action>
    1. In `bert.rs`, add `NomicBertHfConfig` struct with serde:
       ```rust
       #[derive(Debug, serde::Deserialize)]
       pub struct NomicBertHfConfig {
           pub n_embd: usize,          // hidden_size (768)
           pub n_head: usize,           // num_attention_heads (12)
           pub n_layer: usize,          // num_hidden_layers (12)
           pub n_inner: usize,          // intermediate_size (3072)
           pub vocab_size: usize,       // 30528
           #[serde(default = "default_n_positions")]
           pub n_positions: usize,      // max_position_embeddings (8192)
           #[serde(default = "default_nomic_ln_eps")]
           pub layer_norm_epsilon: f64, // 1e-12
           #[serde(default = "default_rotary_fraction")]
           pub rotary_emb_fraction: f32, // 1.0
           #[serde(default = "default_nomic_rope_base")]
           pub rotary_emb_base: f32,    // 1000.0 (NOT 10000!)
       }
       ```

    2. Implement `NomicBertRunner` as a native encoder using existing crabinfer building blocks:
       - **Embedding layer**: word_embeddings (nn::Embedding), NO position embeddings (RoPE applied in attention)
       - **Each encoder layer** (12 layers):
         - LayerNorm (pre-norm, using candle_nn::LayerNorm — NOT RmsNorm, nomic-bert uses standard LayerNorm)
         - Self-attention with fused QKV projection (`Wqkv` weight, shape [3*hidden, hidden]):
           Split into Q, K, V. Apply RoPE to Q and K using `rotary_emb_fraction * head_dim` dimensions.
           RoPE: use `candle_nn::rotary_emb::rope` or compute inline (cos/sin precomputed for max seq_len with base=1000.0).
           Bidirectional attention (no causal mask) — use `Tensor::matmul` for Q*K^T, scale by 1/sqrt(head_dim), softmax, then matmul with V.
           Output projection (`out_proj`).
         - LayerNorm (pre-norm for MLP)
         - SwiGLU MLP: Use the existing `SwiGluMlp` pattern from models/mod.rs or implement inline.
           nomic-bert MLP has fc1 (hidden -> 2*intermediate) split into gate+up, then fc2 (intermediate -> hidden).
           The weight name is `mlp.fc1.weight` [2*n_inner, n_embd] and `mlp.fc2.weight` [n_embd, n_inner].
       - **Final LayerNorm** after all layers.
       - **embed()**: tokenize -> forward through all layers -> masked_mean_pool -> L2 normalize.

    3. Weight key prefix: nomic-embed safetensors uses `model.` prefix. Use the config.json `model_type` field to try `vb.pp("model")` prefix. If tensor names start with `model.`, use that prefix for VarBuilder construction.

    4. Implement `ModelRunner` for `NomicBertRunner`:
       - `forward()`: return Err (encoder-only)
       - `embed(input_ids)`: reshape to [1, seq_len], run full encoder, masked_mean_pool, L2 normalize
       - `clone_model()`: store model_dir path and reload on clone (same as BertEmbeddingRunner)
       - Trait accessor methods delegate to stored ModelConfig

    5. Add `NomicBert` dispatch in `load_model_from_safetensors_with_backend`:
       ```rust
       ModelArchitecture::NomicBert => {
           let model = super::models::bert::NomicBertRunner::from_safetensors(
               model_dir, device, weight_dtype,
           )?;
           return Ok(Box::new(model));
       }
       ```

    CRITICAL PITFALLS TO AVOID:
    - nomic-bert config uses `n_embd`, `n_head`, `n_layer`, NOT standard BERT field names
    - RoPE base is 1000.0 (NOT 10000.0 like Llama)
    - Weight prefix is `model.` — use `vb.pp("model")` when loading
    - No token_type_embeddings in nomic-bert
    - Use standard LayerNorm (not RmsNorm) — nomic-bert uses pre-LN with standard layer norm
    - SwiGLU: fc1 weight is [2*n_inner, n_embd], needs to be split into gate and up halves
  </action>
