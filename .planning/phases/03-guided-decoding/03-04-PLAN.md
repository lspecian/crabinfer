<objective>
Add unified guided completions endpoint and configurable error behavior.

Purpose: The regex constraint path (GDEC-02) is implemented at the engine level but not exposed via any server API. A new `POST /v1/guided/completions` endpoint provides a canonical place for all constrained generation (both regex and JSON Schema), while `response_format` on `/v1/chat/completions` remains for OpenAI backward compatibility. Configurable error behavior (strict vs graceful degradation) lets production deployments choose between failing fast (400) or generating unconstrained with a warning.

Output: New guided endpoint module, request/response types, route registration, configurable strict_constraints flag.
</objective>
