    - is_fp32_weight("model.layers.0.self_attn.q_proj.weight") -> false
    - is_fp32_weight("model.layers.0.mlp.gate_proj.weight") -> false
  </behavior>
  <action>
Add to quantization.rs (after the KVCacheDType impl block):

1. **ServingDType enum** with variants: Auto, F32, F16, BF16. Implement Default (Auto), FromStr (accept "auto", "f32", "fp32", "f16", "fp16", "bf16"; error on unknown), Display ("auto", "f32", "f16", "bf16").

2. **detect_best_dtype()** function:
   - `#[cfg(feature = "cuda")]` version: access `device` as `Device::Cuda(cuda_dev)`, call `cuda_dev.cuda_stream().context().compute_capability()`. If `(major, _)` where major >= 8 -> BF16, major >= 7 -> F16, else F32. On error -> F32.
   - `#[cfg(not(feature = "cuda"))]` version: always returns F32.
   - Non-CUDA devices (Device::Cpu, Device::Metal): return F32.

3. **resolve_serving_dtype(dtype: ServingDType, device: &Device) -> candle_core::Result<DType>**:
   - Auto: call detect_best_dtype, log at INFO level with rationale string.
   - BF16: `#[cfg(feature = "cuda")]` check that SM >= 80 if device is Cuda; if not, return `Err(candle_core::Error::Msg("BF16 requires Ampere (sm_80+) GPU, detected sm_{sm}. Use --dtype f16 or --dtype auto instead."))`. Non-CUDA devices: allow BF16 (candle CPU supports it).
   - F16: return Ok(DType::F16).
   - F32: return Ok(DType::F32).
   - Log at INFO: "Serving dtype: {resolved:?}" for all paths.

4. **is_fp32_weight(name: &str) -> bool**: Returns true for weight names that must stay FP32. Match patterns:
   - `name.ends_with("embed_tokens.weight")` or `name.ends_with("embed.weight")`
   - `name == "model.norm.weight"`
   - `name.ends_with(".input_layernorm.weight")`
   - `name.ends_with(".post_attention_layernorm.weight")`
   - `name.ends_with("_norm.weight")` (catches q_norm, k_norm, ln_1, ln_2, any norm)
   - `name.ends_with(".ln_1.weight")` or `name.ends_with(".ln_2.weight")` (GPT-2 style, redundant with _norm but explicit)

5. **Update Wave 0 test stubs**: Replace `todo!()` in the `serving_dtype_tests` module with real assertions that exercise the new types and functions.

Make `ServingDType`, `resolve_serving_dtype`, and `is_fp32_weight` all `pub`.
