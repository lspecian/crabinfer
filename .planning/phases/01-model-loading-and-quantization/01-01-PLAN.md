    Modify `load_serving_engine()` in `crabinfer-server/src/lib.rs` to detect HF repo IDs and resolve them to local directories before model loading:

    1. At the top of `load_serving_engine()`, after the `model_path` line, add:
       ```rust
       let model_path = if crabinfer_core::serving::hub_download::is_hf_repo_id(&config.model_path) {
           tracing::info!("Detected HuggingFace repo ID: {}", config.model_path);
           let rt = tokio::runtime::Handle::current();
           let repo_id = config.model_path.clone();
           let local_dir = rt.block_on(async {
               crabinfer_core::serving::hub_download::ensure_model_cached(&repo_id).await
           }).map_err(|e| format!("Failed to download model from HuggingFace Hub: {e}"))?;
           tracing::info!("Model cached at: {}", local_dir.display());
           local_dir
       } else {
           std::path::PathBuf::from(&config.model_path)
       };
       let model_path = model_path.as_path();
       ```

    2. The rest of the function already uses `model_path` as a `&Path`, so the existing `is_safetensors` check, model loading, and tokenizer loading all work unchanged.
